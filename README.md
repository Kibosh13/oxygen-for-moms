# oxygen for moms — лендинг листа ожидания

Чистый HTML/CSS/JS, mobile first, без сборки. Работает прямо на GitHub Pages.

```
index.html   — разметка и тексты
styles.css   — стили (цвета в :root)
main.js      — анимации, меню, аккордеон, дыхательная пауза, форма
assets/      — картинки сайта
```

## Картинки
Сайт сначала ищет файл в `assets/`. Если его нет — показывает временное фото со стока (Unsplash, бесплатная лицензия).
Чтобы поставить свою картинку, достаточно загрузить файл с нужным именем в `assets/` — код менять не надо.

| Файл | Где | Формат |
|---|---|---|
| hero-desktop.jpg | главный экран, компьютер | 3:2, героиня справа |
| hero-mobile.jpg | главный экран, телефон | 2:3, героиня сверху |
| intro.jpg | блок «О клубе» | 9:11 |
| dir-body / dir-mind / dir-pediatr / dir-payments / dir-nanny .jpg | направления | 1:1, объект по центру |
| silk-sage.jpg | полоса с цитатой | 3:2, центр светлый |
| silk-sand.jpg | фон формы записи | 3:2 |
| atmosphere.jpg | блок «Как устроено» | 2:3 |
| founder.jpg | Екатерина | 3:4 |

## Перенос в Tilda (Zero Block)

**Шрифты:** Cormorant Garamond (300/400, italic) — заголовки; Manrope (400/500) — текст.

**Цвета:**
| Роль | HEX |
|---|---|
| Глубокая олива (тёмные блоки) | `#1F2620` |
| Крем (фон) / светлый | `#F3EEE5` / `#FAF7F1` |
| Песок (фон блоков) | `#EAE3D6` |
| Олива / шалфей / светлый шалфей | `#4F5B46` / `#9DAA8F` / `#D5DBCB` |
| Бронза (акцент, hover кнопок) | `#A87B52` |
| Текст / вторичный | `#23211E` / `#5E5850` |

**Размеры (десктоп / мобайл 390):** H1 124 / 62 px, Cormorant 300, межстрочный 0.92 · H2 секций 92 / 41 px · кнопки прямоугольные, высота 58 px, текст 15 px.

**Анимация:**
- Прелоадер: тёмный экран, кольцо «вдох» и логотип, через 1.3 с уезжает вверх.
- H1: строки выезжают снизу из-под маски, 1.5 с, вторая строка +0.12 с.
- Фото: раскрываются шторкой снизу вверх (clip-path) с лёгким уменьшением масштаба, 1.6 с.
- Текст «О клубе» проявляется по словам при прокрутке.
- Фото первого экрана, шёлк и фон формы — параллакс 10–18%.
- Направления: аккордеон; на десктопе картинка слева меняется при наведении.
- Дыхательная пауза: круг растёт 4 с (вдох) и уменьшается 6 с (выдох), 3 круга.
- Плавный скролл Lenis только на десктопе; на телефоне — нативный. Blur-фильтры на больших площадях не используются.

**Форма:** заменить демо-форму на штатную форму Тильды (Имя, Телефон/e-mail, чекбокс согласия) и подключить приём заявок.
