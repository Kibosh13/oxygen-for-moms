# oxygen for moms — лендинг листа ожидания

Чистый HTML/CSS/JS, mobile first, без сборки. Работает прямо на GitHub Pages.

```
index.html   — разметка и тексты
styles.css   — стили (цвета в :root)
silk.js      — «живой шёлк»: анимированный фон на WebGL
main.js      — слайдер, меню, аккордеон, чат, дыхательная пауза, формы
assets/      — картинки сайта
```

## Живой шёлк
Фон первого экрана, дыхательной паузы и тарифа рисуется кодом, а не видео: складки ткани медленно текут и реагируют на мышь.
- Палитры: `sage` (шалфей), `olive` (тёмная олива), `sand` (песок) — в начале `silk.js`.
- На телефоне рендер в пониженном разрешении и до 30 кадров/с; вне экрана анимация останавливается.
- Если WebGL недоступен — показывается мягкий градиент. При «уменьшении движения» — статичный кадр.

## Картинки
Сайт сначала ищет файл в `assets/`. Если его нет — показывает временное фото со стока (Unsplash), а у команды — монограмму.
Чтобы поставить свою картинку, достаточно загрузить файл с нужным именем в `assets/` — код менять не надо.

| Файл | Где | Формат |
|---|---|---|
| pillar-body / pillar-mind / pillar-baby / pillar-kids / pillar-money .jpg | пять опор | 4:5, объект по центру |
| bonus-nanny.jpg | бонус: гайд по няне | 1:1 |
| team-ekaterina / team-psychologist / team-child-psychologist / team-pediatrician / team-monk / team-accountant .jpg | команда | 3:4, вертикальный портрет |

## Перенос в Tilda (Zero Block)

**Шрифты:** Cormorant Garamond (300/400, italic) — заголовки; Manrope (400/500/600) — текст.

**Цвета:** олива `#1F2620`, крем `#F3EEE5`, светлый шалфей `#EEF0E7`, шалфей `#9DAA8F`, олива-акцент `#4F5B46`, бронза `#A87B52`, текст `#23211E` / `#5E5850`.

**Первый экран:** слайдер из 3 слайдов, автопрокрутка 8 с, пауза при наведении, свайп на телефоне. При смене слайда шёлк плавно меняет цвет (шалфей → олива → песок). Логотип OXYGEN / for moms — Cormorant 300, разрядка 0.2em / 0.32em.
Живой шёлк в Тильде: блок T123 с `<canvas data-silk data-palette="sage">` и подключённым `silk.js`, поверх — Zero Block с прозрачным фоном.

**Анимация:** появление блоков — сдвиг 34 px + прозрачность, 1.4 с; логотип раскрывается снизу вверх; чат — сообщения по очереди с «печатает…»; дыхательная пауза — 4 с вдох / 6 с выдох, 3 круга.

**Формы:** лист ожидания и заявка специалиста — демо. В Тильде заменить на штатные формы с приёмом заявок.
