# oxygen for moms — лендинг листа ожидания

Чистый HTML/CSS/JS, mobile first. Без сборки — работает прямо на GitHub Pages.

```
index.html   — разметка и тексты
styles.css   — стили (токены цветов в :root)
main.js      — анимации, плавный скролл, форма
```

## GitHub Pages
Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.

## Фото
Сейчас стоят временные стоковые фото с Unsplash (бесплатная лицензия), подключены ссылками и тонированы CSS-фильтром под палитру.
Чтобы заменить на свои: положить файл в `assets/` и поменять `src` у нужного `<img>` в `index.html`.
Пропорции: главное фото 4:5, вставка 1:1, фото модулей 4:3.

## Перенос в Tilda (Zero Block)

**Шрифты:** Cormorant Garamond (300/400/500, italic) — заголовки; Manrope (400/500/600) — текст. Оба есть в Google Fonts и подключаются в Тильде.

**Цвета:**
| Роль | HEX |
|---|---|
| Фон (беж) | `#F3EEE6` |
| Карточки | `#FBF8F3` |
| Шалфей / светлый | `#A9B5A0` / `#D7DDD0` |
| Шалфей тёмный (акценты) | `#5F6B58` |
| Текст / вторичный | `#2E2A26` / `#6B635B` |
| Кнопка (терракота) / hover | `#C07A5A` / `#A8664A` |

**Размеры (десктоп / мобайл 390):**
- H1 «Верни себе воздух.» — 128 / 58 px, italic 300, межстрочный 0.92
- Подзаголовок H1 — 34 / 22 px, Cormorant 400
- H2 (лид) — 17 / 16 px, Manrope 400, цвет `#6B635B`
- Заголовки секций — 72 / 36 px, Cormorant 300
- Кнопка — радиус 999, высота ~76 px, две строки 16/12.5 px
- Карточки — радиус 28, фон `#FBF8F3` 70%
- Фото — радиус 28 (главное), 22 (вставка), 18 (модули)

**Анимация в Zero Block (Step-by-step / Basic):**
- Появление: Fade In + сдвиг вверх 28 px, длительность 1.3 с, easing `ease-out`, задержка 0.1 с между элементами.
- H1: каждое слово отдельным элементом, сдвиг снизу 100%, 1.4 с, задержка +0.09 с на слово.
- Главное фото: при загрузке scale 1.16 → 1.06 за 2.4 с; при скролле лёгкий параллакс, вставка движется навстречу.
- Плашка «вдох / выдох»: точка loop, scale 0.6 → 1.4 (4 с) → 0.6 (6 с), текст меняется синхронно.
- Бегущие слова: Scroll-анимация (Parallax по X), ±15% ширины, направления навстречу.
- Фоновые пятна: PNG с радиальным градиентом, Parallax 10–20%. **Не использовать blur-фильтры** — тормозят на телефонах.
- Плавный скролл на десктопе: Lenis через блок T123 (код из `main.js`, раздел 3). На мобильных — нативный скролл.

**Форма:** заменить демо-форму на штатную форму Тильды (поля: Имя, Телефон/e-mail, чекбокс согласия) и подключить приём данных.
